## ruby 程序的结构和运行
### 词法结构
#### 注释
- ruby 中的注释以 `#` 字符开始并持续到该行结束
- 通常情况下通过在每一行前添加一个 `#` 字符来表示多行注释,如
```ruby
#
# xxxxx
# sdsdmkslmdf
#
```
##### 嵌入文档注释
Ruby支持另外一种称为嵌入式文档的多行注释风格。这种注释以一个 `=begin` 为开头，并以一个 `=end`结尾。任何出现在在`begin`之后的文本都会被作为注释而忽略掉，前提是这些文本和 `begin` 之间至少要有一个空格作为分界。位于 `end` 之后的文本也同样遵循这个规则。
> 注意: `=`必须作为改行的第一个字符，这样才能使嵌入式文档生效
>
```ruby
=begin This is used to begin a comment.Now it is itself commented out!
    The code that goes here is no longer commented out
=end
```
利用嵌入式文档，可以注释调大段的代码，而无需在每一行代码前添加 `#` 字符。
嵌入式文档，既可以用在程序中插入大段的文档，也可以在ruby程序中嵌入其他语言边学的源代码（类似md文件中的三个反引号）。
嵌入式文档通常会被一些后期处理工具使用，在 `=begin` 之后，通常跟着一个标识符来表明希望哪种工具来处理该注释。
##### 文档化的注释
在Ruby的程序里的方法、类以及模块定义之前，可以包含嵌入式的API文档，这些文档是一些遵循特殊格式的注释
